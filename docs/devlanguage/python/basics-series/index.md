# Python 基础客户教程：从会运行到能交付

这是一套面向实际数据处理工作的 Python 基础教程。它不把语法拆成彼此孤立的名词，而是围绕一条完整工作流展开：把客户名单、订单明细和回访记录读进程序，写出清楚的检查规则，批量生成结果，再把脚本交给同事稳定运行。

课程使用客户运营的常见数据作为贯穿案例：`customers.csv` 保存客户信息，`orders.csv` 保存订单，`followups.csv` 保存回访记录。示例中的字段、规则和输出都可以替换为自己的业务口径。

## 阅读路径

如果刚开始接触 Python，请按顺序学习。先看 EP00 建立全图；中间二十四篇完成运行、数据、规则、文件和交付主线；最后用 EP25 补齐对象建模，再用 EP26 把全部能力收成第一个可交付工具的路线。

## 学习后的交付标准

完成这一系列后，应能独立完成一条小型数据处理链路：明确输入字段和规则，把一份 CSV 或接口数据读进脚本，输出异常清单或汇总报告，并提供运行命令、依赖说明和可复查的日志。对于多部门协作，脚本还应把输入、输出、异常和配置边界写清楚，避免结果只能由原作者解释。
