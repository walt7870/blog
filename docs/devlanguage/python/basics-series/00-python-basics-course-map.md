# 这套 Python 基础课会带你从哪里走到哪里

这篇先回答一个比语法更重要的问题：二十多集内容怎样连接，学完以后可以用 Python 做成什么。

## 课程不是语法清单

一个可用工具通常经历同一条路径：启动 Python，读入数据，按规则处理，写出结果，再让别人能复现这次运行。

```text
解释器与路径
  -> 变量与数据结构
  -> 条件与循环
  -> 函数、模块与类
  -> CSV、JSON、文件与 API
  -> 异常、日志、参数与 README
```

贯穿案例是一套客户运营工具：读取客户名单和订单明细，检查缺失字段和异常订单，汇总来源与城市，生成日报，必要时从接口同步数据。

## 六段能力

| 阶段 | 解决的问题 | 关键内容 |
| --- | --- | --- |
| 运行 | 怎样让脚本真正启动 | 解释器、终端、工作目录、路径 |
| 表达 | 怎样让程序读懂一张表 | 类型、列表、字典、集合、元组 |
| 规则 | 怎样把口头判断批量执行 | `if`、`for`、字符串、数字、日期 |
| 组织 | 怎样让代码能继续改 | 函数、模块、类、参数 |
| 连接 | 怎样读写真实输入 | CSV、JSON、文件夹、API |
| 交付 | 怎样让别人也能运行 | 环境、异常、日志、README |

## 学习方式

每篇先确认它要解决的具体问题，再运行最小示例。不要一次复制完整项目；先改一个字段名、一个阈值或一个输入文件，确认结果随之变化。始终把输入、规则、输出和失败信息分开写清楚，它们也是后续所有 Python 项目最可靠的骨架。
