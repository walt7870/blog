# 前端框架比较：更新模型、生态与团队约束

给同一个商品编辑页选择框架，不能只比较计数器代码行数。页面还需要路由、权限、表单、请求缓存、可访问性和上线排错。选型应该说明哪些能力由框架提供、哪些由生态补齐，以及团队愿意长期维护哪些约定。

## 用同一条业务链比较

先固定需求：商品详情由接口读取，名称可编辑，数量改变后重算总价，提交冲突要保留草稿。再分别观察“状态放哪里、如何触发更新、DOM何时提交、服务如何注入、失败如何恢复”。路由和服务端渲染必须以选定的上层方案一起比较。

| 维度 | React | Vue 3 | Angular | Svelte 5 |
| --- | --- | --- | --- | --- |
| 常见表达 | 函数组件与JSX | SFC模板与Composition API | 组件模板与TypeScript | 组件文件与runes |
| 更新入口 | state更新安排渲染 | ref/reactive依赖触发更新 | signal与变更检测等机制 | 编译转换与运行时响应式协作 |
| 常见组织能力 | UI核心与生态组合 | 渐进采用，配套路由和状态生态 | DI、路由、HTTP、表单等体系 | 编译器、运行时与配套应用框架 |
| 必须明确的边界 | React与应用框架分工 | Vue与Nuxt等上层方案分工 | provider作用域和应用配置 | Svelte与SvelteKit分工 |

表格比较的是模型，不是速度排名。各框架都使用编译工具，也都有运行时行为；“React只在运行时”“Svelte没有运行时”都过于粗糙。具体 API 还要和项目使用的主版本一致。

## React：状态快照与渲染提交

React 的状态更新会安排组件重新计算，渲染结果再进入提交阶段。一次渲染读取的是该次状态快照；连续更新若依赖前一次值，应使用相应的函数更新方式。渲染可能重做或被放弃，不能把支付请求直接放进渲染函数。

React 核心不包办所有应用决策。路由、数据加载、服务端组件与部署方式取决于配套框架和库。团队需要约定目录、数据边界、错误处理及测试入口；这些约定也会带来维护成本。详见 [React 组件与状态](./31-react-components-hooks-state)。

## Vue：响应式依赖与组件边界

Vue 3 用 ref、reactive 等建立响应式数据，渲染或计算读取数据时收集相应依赖，变化后安排更新。模板在构建阶段编译，运行时依然需要执行依赖追踪、调度和组件生命周期。

渐进采用适合从已有页面增强起步，也可以用路由、Pinia 和服务端框架组织完整应用。便利不意味着没有边界：解构响应式对象、复制 props、滥用 watch 都可能导致状态关系不清。详见 [Vue SFC 与响应式](./32-vue-sfc-reactivity-composition)。

## Angular：完整体系与作用域约束

Angular 提供相互配合的路由、HTTP、表单、依赖注入和工具链。现代 Angular 可以用 standalone 组件与 signal，不能只沿用早期“所有代码必须围绕NgModule”的描述。

完整体系减少部分库组合决策，但不自动保证业务分层正确。provider 放在应用级还是组件级会影响服务实例寿命；signal 也不取代所有异步流与请求处理。长期多人维护的业务系统可以从统一规范获益，代价是团队要掌握这一整套模型。详见 [Angular 应用结构](./33-angular-di-signals-application-structure)。

## Svelte：编译与运行时共同工作

Svelte 5 的 runes 是由编译器识别的语法入口。`$state` 声明响应式状态，`$derived` 表达派生值，`$effect` 同步外部副作用。依赖仍可在运行时根据实际读取建立，不能把所有数据关系都描述成编译期静态推导完成。

SvelteKit 负责更完整的路由、数据加载和服务端应用能力。旧项目中的 `$:` 与 Svelte 5 runes 模式也有差异，迁移时应明确文件采用哪种模式。编译产物较直接，不意味着任何真实页面都比其他框架更快。

## 做一份可复核的选型试验

用同一接口合同、同一数据量、同一设计实现商品页，至少包括错误、空态、冲突、长名称和键盘流程。分别记录新增依赖、业务代码与框架胶水、构建输出、真实设备交互以及新成员理解成本。

如果主要风险是旧系统迁移，优先验证嵌入现有页面和渐进替换；如果主要风险是多人长期协作，验证目录、服务作用域和测试约定；如果主要风险是内容首屏，比较配套 [渲染架构](./24-web-rendering-architecture)。有现成组件库和团队积累时，把迁移成本计入结果，不能只凭一个微基准重写系统。
