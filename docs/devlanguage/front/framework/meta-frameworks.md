# 元框架与全栈框架

元框架建立在 React、Vue、Svelte 等组件框架之上，负责路由、渲染模式、数据加载、构建部署和服务端能力。它们解决的不是“怎么写组件”，而是“一个完整 Web 应用如何组织和交付”。

商品介绍、库存和个人订单虽然在同一个站点，更新规律却不同：介绍可在构建时生成，库存需要请求时读取，订单还需要身份隔离。选型的第一步是按数据与页面划分运行合同，而不是给整个网站贴上唯一的SSR标签。

## 主流框架

| 框架 | 基础生态 | 适用场景 |
| --- | --- | --- |
| Next.js | React | 官网、内容站、SSR/SSG、全栈 React 应用 |
| Nuxt | Vue | Vue 生态下的 SSR/SSG、内容站、业务应用 |
| SvelteKit | Svelte | Svelte 全栈应用、轻量 SSR/SSG 项目 |
| Astro | 多框架 | 内容站、文档、博客、营销页、岛屿架构 |
| React Router框架模式 | React | 路由模块、loader/action、服务端或静态交付；Remix v2应用可迁移至v7 |
| Umi | React | 国内中后台、企业级路由和工程规范 |

## 渲染模式

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| CSR | 浏览器端渲染，服务端只返回静态入口 | 内部后台、登录后应用 |
| SSR | 请求时在服务端渲染 HTML | SEO、首屏性能、动态内容 |
| SSG | 构建时生成静态 HTML | 文档、官网、博客、营销页 |
| ISR / 增量生成 | 静态页面按策略更新 | 内容频繁变化但不需要每次实时渲染 |
| Islands | 页面大部分静态，局部组件激活 | 内容站和性能敏感页面 |

## 选型

React 项目需要 SSR、文件路由、服务端接口和成熟托管生态时，优先看 Next.js。Vue 项目需要类似能力时，优先看 Nuxt。内容站、文档和营销页如果交互较少，应重点评估 Astro，因为它能减少默认发送到浏览器的 JavaScript。

Umi 在国内中后台项目中常见，适合已有 Ant Design、权限、菜单、路由约定和企业工程规范的团队。React Router框架模式沿用Remix的数据加载与提交思路，维护旧Remix项目时应区分版本和迁移合同，不能把两套路由配置混写。

## 以商品与订单拆分运行合同

公开介绍页可在构建时读取内容并输出HTML，更新内容后重新构建；价格与库存若要求新鲜数据，可在请求时渲染或由浏览器读取API。订单页必须携带访问者身份，服务器查询和缓存键都要隔离用户，不能把某次请求的订单HTML作为全站公共缓存。

SSR输出HTML后，客户端交互组件通常还需要下载脚本并激活。浏览器与服务器初始状态不一致会导致hydration问题，例如服务端使用本地时区格式化日期、客户端使用另一时区，或首屏直接读取localStorage。把环境相关逻辑放到明确边界，不能只用隐藏警告处理差异。

| 业务对象 | 执行位置 | 更新与失败合同 |
| --- | --- | --- |
| 商品图文介绍 | 构建器生成HTML，CDN提供 | 发布重建；构建数据源不可用时发布失败或沿用已验证版本 |
| 库存与实时价格 | 服务器或浏览器请求API | 明确刷新频率、过期标识、超时和降级 |
| 登录后的订单 | 受鉴权的服务器/API | 按身份授权与缓存隔离，拒绝跨用户读取 |
| 数量选择和表单草稿 | 浏览器组件 | 本地交互，提交时服务器重新校验 |

每个框架对缓存、路由文件和adapter的实现不同，`ISR`不是所有框架通用的配置项。部署前按实际版本检查“哪些页面预生成、哪些路径要请求运行时、哪些资源需要保留旧版本”。

## 注意点

元框架会影响部署方式。SSR 应用需要 Node.js 服务、Serverless 或边缘运行环境；SSG 可以直接部署到 Nginx、对象存储或 CDN。选型前要确认团队是否能维护对应运行时，而不是只看开发体验。

| 现象 | 检查点 |
| --- | --- |
| 本地正常线上失败 | SSR 运行环境、环境变量、Node.js 版本 |
| SEO 不生效 | 页面是否真实 SSR/SSG，是否被客户端异步渲染覆盖 |
| 构建时间过长 | 页面数量、静态生成策略、远程数据请求 |
| 缓存混乱 | HTML、数据接口、CDN 和浏览器缓存层级 |

验收至少覆盖直接打开深层URL、刷新、登录后换账号、浏览器前进后退、API超时以及旧页面加载新发布资源。可以用`curl -s http://localhost:端口/商品路径`检查初始HTML是否包含商品正文，但这只验证返回内容，仍需浏览器验证交互和客户端导航。[部署页](../deployment/)说明静态资源与运行时服务如何共同交付。
