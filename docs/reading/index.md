# 阅读记录

阅读笔记记录概念如何影响实际判断，不把书中的建议当作适用于所有环境的定律。读完一本书，可以选一个正在发生的问题，写下原来的做法、尝试的改变和观察到的结果；没有验证过的感受与已经发生的效果分开记录。

## 个人管理与协作

[《高效能人士的七个习惯》](./2022-07-31/高效能人士的7个习惯.md)从个人选择、目标与优先级，走向合作、倾听和持续更新。笔记以一次项目延期为例，说明“主动负责”和“共同找办法”怎样转化为动作，也说明个人习惯不能替代组织资源与工作制度。

可以先看文中的关系图，再选择当前最需要的一环：任务太多时看目标与优先级，协作僵持时看倾听与共同目标，长期疲惫时检查工作节奏和恢复条件。每次只试一种改变，给结果留出观察时间。
