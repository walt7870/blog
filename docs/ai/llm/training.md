# 大模型训练与微调

大模型训练常包含预训练、监督微调和偏好优化，但不是每个项目都必须顺序执行所有阶段。预训练和SFT描述训练任务，LoRA与QLoRA描述参数适配方式；一次SFT可以使用全参数更新，也可以使用LoRA。

![冻结底座与LoRA低秩分支的参数更新关系](/ai/lora-parameter-path.svg)

## 训练链路

| 阶段 | 目标 | 产物 |
| --- | --- | --- |
| 预训练 | 学语言、知识关联、生成能力 | 基础模型 |
| SFT | 学指令、格式、领域任务 | 指令模型 |
| 偏好对齐 | 学更符合人类偏好的回答 | 更可用的助手模型 |
| 评估与回流 | 找失败样例并修正 | 新数据、新规则、新版本 |

## 预训练

预训练从大规模数据中学习语言规律、事实关联、代码模式和推理样式，也可能记忆并复现部分训练文本。因此数据授权、重复样本和敏感信息清理仍需检查，不能用“模型只学规律”消除泄露风险。

底座为后续适配提供起点，数据、目标和后训练仍会改变具体任务表现。多数应用团队选择已有底座，再按知识时效、行为稳定性和资源预算选择RAG、SFT或工具；不能把一次微调理解为无条件突破所有能力限制。

## SFT

SFT 的目标是让模型按标准样例完成任务。它适合固定口径、固定格式、固定流程的场景。详细说明见 [SFT](./sft.md)。

SFT 的关键不是训练脚本，而是数据质量：

- 输入是否覆盖真实问法。
- 输出是否稳定一致。
- 异常、拒答、缺信息场景是否覆盖。
- 是否存在互相矛盾的样例。

## LoRA

LoRA 是参数高效微调方法。它保留底座模型主体，只训练少量低秩矩阵来影响模型行为。

适合：

- 想低成本适配领域风格。
- 一个底座模型挂多个业务适配。
- 训练资源有限。

不适合：

- 试图补充大量实时变化知识。
- 底座模型本身不会目标任务。
- 数据质量差，只想靠训练“洗干净”。

LoRA 更像给模型加可拆卸适配件，不是重造模型。

对线性层，更新可写成 `W' = W + (alpha/r)BA`：冻结原矩阵W，训练A和B。若W为4096×4096，秩r=8，则W有16777216个参数，A和B共`8×4096 + 4096×8 = 65536`个，为原矩阵的1/256；这只比较该层参数数量，不代表整模型显存或训练时间缩小256倍。激活仍要保留，优化器可能还更新配置选中的其他模块。

适配器必须绑定确切底座、目标模块、Tokenizer与训练配置。合并权重后再加载一次同一适配器可能重复施加更新；量化合并还可能引入额外误差，应比较固定输入的输出与任务指标。

## QLoRA

QLoRA 在量化、冻结的底座上训练LoRA适配层。典型4位权重在计算时按配置反量化，适配器和优化器状态并非全为4位；它能减少底座存储压力，但不能仅按权重大小估算训练显存。

需要注意：量化和微调都会影响精度，训练后必须用独立评估集检查任务效果和回归风险。

## RLHF 与 DPO

SFT 教模型“标准答案长什么样”，偏好对齐进一步教模型“两个答案哪个更好”。

- 典型RLHF流程：用人类偏好训练奖励模型，再通过强化学习更新策略；具体方案可能不同。
- DPO：用成对偏好数据及参考策略直接优化目标，不要求另训显式奖励模型或在训练循环中在线采样强化学习轨迹。

它们常用于改善回答质量、拒答边界、帮助性和安全性。但偏好数据也会带来取向偏差，需要明确评估标准。

例如同一退款问题，偏好数据可以比较“保留审核条件与工作日范围”与“无依据承诺明天到账”。若标注者只偏爱更短、更肯定的回答，优化可能奖励错误承诺。偏好标签应检查事实和业务后果，不能把用户喜欢直接当成正确。

## 微调还是 RAG

| 目标 | 优先方式 |
| --- | --- |
| 补充经常变化的知识 | RAG |
| 查询实时状态 | 工具调用 |
| 固定输出格式和语气 | SFT / LoRA |
| 改善任务处理流程 | SFT + 规则样例 |
| 多业务共享底座但风格不同 | LoRA / Adapter |
| 提升通用能力上限 | 换更强底座或继续预训练 |

## 数据闭环

上线后的失败样例应回流，但不能直接丢进训练集。需要先分类：

- 是知识缺失：放入知识库或工具。
- 是格式不稳定：补 SFT 样例。
- 是边界拒答错误：补偏好或安全样例。
- 是工具结果错误：修工具或数据源。
- 是用户输入不清：改交互和澄清策略。

## 总结

训练与微调要先判断目标：补知识、改行为、调风格、降成本还是提上限。LoRA 和 QLoRA 适合低成本行为适配，SFT 适合固化任务格式，RAG 适合外部知识，工具调用适合实时动作。训练不是万能修复器，错误目标会把成本花在错误层。

这一页只给出判断框架。每个阶段怎样做、要多少显存和算力、训练曲线怎么看、怎样证明训练后更好，以及语音、视觉和向量模型怎样训练，见 [模型训练与调优](../model-training/) 系列；想先动手，可以跟着 [实践：用 LoRA 微调资料助手](../model-training/lora-practice.md) 在笔记本上跑一遍。
