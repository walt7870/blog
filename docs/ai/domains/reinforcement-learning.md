# 强化学习

强化学习让智能体通过与环境交互，根据长期奖励学习行动策略。它与监督学习的区别是没有直接给出每一步正确答案，行动还会改变后续状态和可见数据。

## 基本对象

| 对象 | 含义 | 示例 |
| --- | --- | --- |
| 状态 State | 当前环境信息 | 车辆位置、速度、道路情况 |
| 动作 Action | 可执行选择 | 加速、刹车、转向 |
| 奖励 Reward | 环境对动作的即时反馈 | 前进奖励、碰撞惩罚 |
| 策略 Policy | 从状态选择动作的方法 | 当前情况下各动作概率 |
| 回报 Return | 一段时间内累计奖励 | 完成任务的长期收益 |

## 马尔可夫决策过程

经典强化学习通常用 MDP 表示环境：给定当前状态和动作，下一状态与奖励的分布不再依赖更早历史，这是建模假设，不是所有现实观测都天然满足。看不到完整状态时，需要历史表示或部分可观测模型。折扣因子控制未来奖励在回报中的权重。

![仓库机器人在仿真环境中选择动作并接收奖励](/ai/rl-state-action-loop.svg)

例如机器人送货，状态至少包含位置、剩余电量和可见障碍，动作是移动或充电。只奖励“每送一单加 1”可能诱导它耗尽电量后停在通道中；将碰撞、电量底线作为可执行安全约束，比只加一个很小的扣分更可靠。

同一条两步轨迹的奖励若为 `[-1, 10]`，折扣因子为 0.9，则起点回报为 `-1+0.9×10=8`。如果电量不足导致第二步无法送达，这个回报就不存在。策略必须同时理解动作对未来可达状态的影响，不能只按当前奖励挑动作。

## 探索与利用

- 利用：选择当前认为最好的动作。
- 探索：尝试不确定动作，获得新信息。

许多在线学习算法通过探索获得信息，但真实医疗、金融和物理控制中的试错可能代价很高。离线强化学习可以利用已有轨迹，无需直接在线探索；同时要防止对历史数据未覆盖的动作过度乐观。仿真表现也不保证现实有效，应检查环境差异、动作约束和策略回滚。

## 价值方法与策略方法

- 价值方法估计某状态或动作未来能获得多少回报，例如 Q-Learning。
- 策略方法直接优化行动概率。
- Actor-Critic 同时学习策略和价值估计。

深度强化学习使用神经网络表示价值或策略，能处理高维状态，但训练稳定性和样本效率仍是主要难点。

## 奖励设计

系统会优化被定义的奖励，而不是设计者心中没有写出的目标。奖励不完整可能导致“钻空子”：为了提高停留时长推荐低质量内容，或为了快速完成任务采取高风险动作。

奖励应结合约束、长期目标和人工审查，并测试极端策略。

## 与大模型对齐的关系

RLHF 的常见流程使用人类偏好训练奖励模型，再优化语言模型策略。DPO 则可从偏好对直接优化相对输出概率，常见实现不需要单独奖励模型和在线强化学习循环。两者都依赖偏好数据质量，不能保证事实正确。

## 适用边界

强化学习适合连续决策、行动影响未来、奖励可定义且存在可训练环境的任务。如果问题只是对独立样本分类，监督学习通常更直接可靠。

生产使用还要评估最坏情况、安全约束、策略回滚和环境变化，而不只是平均累计奖励。
