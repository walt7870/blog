# 神经网络与反向传播

神经网络是由可学习参数和非线性变换组成的函数。训练过程通过样本不断调整参数，使网络逐步逼近目标映射。

## 一个神经元

最简单的神经元先计算输入的加权和，再经过激活函数：

```text
z = x1*w1 + x2*w2 + ... + xn*wn + b
y = activation(z)
```

权重参与输入的组合，偏置提供平移，激活函数引入非线性。权重数值受输入尺度和后续层影响，不能直接作为业务特征的重要性解释。

## 为什么需要多层

如果每层只有线性变换与偏置，叠加后整体仍等价于一个仿射变换。ReLU、GELU、Sigmoid 等激活函数引入非线性，使网络能够组合出弯曲边界和复杂模式。

多层网络会形成层次化表示，但并不是每一层都能被简单解释为一个人类概念。表示来自训练目标、数据和网络结构共同作用。

## 前向传播示例

一个二分类网络可能是：

```text
输入特征(20维)
  -> Linear(20, 64)
  -> ReLU
  -> Linear(64, 16)
  -> ReLU
  -> Linear(16, 1)
  -> logit（未压缩分数）
```

输入批次形状为 `[B,20]`，输出为 `[B,1]`。训练时可将同形状的浮点 0/1 标签直接交给 `BCEWithLogitsLoss`，它已包含数值稳定的 Sigmoid 与交叉熵计算；不要先额外做一次 Sigmoid。推理时才用 `sigmoid(logit)` 转成分数，再按验证集选定阈值分类。

## 损失与反向传播

二分类常用交叉熵衡量预测概率和真实标签的差异。反向传播从损失出发，按链式法则计算每层参数的梯度。

![单参数模型的梯度、学习率与更新结果](/ai/gradient-update-example.svg)

图中的 `x=2、y=4、w=1` 给出损失 2、梯度 -4。反向传播计算梯度，优化器再用学习率更新参数，两者不是同一步。更深的网络只是把链式求导继续经过更多运算，自动微分不负责判断业务标签是否正确。

现代框架会自动构建计算图。开发者需要保证：损失定义正确、梯度没有意外截断、数值稳定、参数确实被优化器管理。

## 激活函数

| 激活函数 | 特点 | 常见位置 |
| --- | --- | --- |
| ReLU | 计算简单，正区间梯度稳定 | CNN、MLP 隐藏层 |
| GELU | 平滑门控，现代 Transformer 常用 | Transformer 隐藏层 |
| Sigmoid | 输出压到 0 到 1 | 二分类输出、门控 |
| Softmax | 把多个分数转换成概率分布 | 多分类输出、Attention 权重 |

隐藏层和输出层的激活函数承担不同职责，不能只按习惯替换。

## 初始化和归一化

参数初始化不当会导致信号逐层放大或衰减。Xavier、Kaiming 等初始化根据层宽控制方差。

BatchNorm、LayerNorm 等归一化技术改善训练稳定性：

- BatchNorm 训练时使用批统计量；常见默认设置还维护运行统计量供评估使用。小批次和模式切换需要单独检查。
- LayerNorm 按指定特征维度归一化，常见于 Transformer，通常不依赖其他样本的批统计量。

## 梯度问题

- 梯度消失：前层几乎得不到更新，深层网络难训练。
- 梯度爆炸：梯度数值迅速增大，损失可能变成 NaN。
- 死亡 ReLU：神经元长期落在零梯度区间。

残差连接、归一化、合理初始化、梯度裁剪和激活函数选择都能改善这些问题。

## 参数量与计算量

参数量表示模型需要存储多少权重，但运行成本还取决于计算量、输入长度和中间激活。

例如大语言模型生成时，KV Cache 可能占据大量显存；视觉模型处理高分辨率图片时，中间特征图可能比参数更耗显存。因此不能只用参数量判断部署成本。

## 一个可靠的训练检查顺序

1. 检查输入形状、数值范围和标签。
2. 用极小数据集确认模型能过拟合。
3. 确认损失下降且梯度非零。
4. 查看训练与验证曲线。
5. 对典型错误样本做人工分析。
6. 再调整网络规模、优化器和正则化。

神经网络的核心并不神秘：它是可微分函数、损失目标和梯度优化的组合。复杂模型只是在结构、规模和训练数据上更大。
