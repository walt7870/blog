# RSI 递归自我改进

递归自我改进讨论的是：AI 参与改进自身系统，而改进结果又帮助后续改进。它涉及模型、工具、实验与验证，也涉及如何区分真实收益、答案修订和远期能力愿景。

当前专题包含一篇完整入门文章及对应视频。从系统组成和具体失败出发，先理解两轮回流，再比较研究证据，最后讨论使用方式、影响和失效边界。

![文件工具在两轮改进中使用前一轮诊断能力的反馈路径](/ai/rsi/two-round-feedback.svg)

例如文件编辑工具第一轮学会区分“文本不存在”和“匹配不唯一”，第二轮添加预览时实际使用这个诊断。回流路径说明改进被用到；是否节省时间、减少错误，还需要新任务和同预算对照。反复让模型重写同一条答案，不能直接证明系统获得了持久的自我改进能力。
