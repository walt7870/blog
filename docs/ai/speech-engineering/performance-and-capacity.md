# 性能、并发与资源治理

单路识别很快，高并发却迟迟拿不到最终句子，常见原因是任务排队。会议转写又同时运行预览、最终识别、角色证据和目标身份判断：入口接收了多少连接，与每个模型能同时处理多少任务是两种容量。

## 先分解等待，再调整模型

曾有性能回退表现为首字变化不大、最终结果随并发增加显著变慢。拆开队列、编码、解码和投递时间后，等待集中在最终识别队列；服务编排与推理运行时的并发配置未对齐。修复方向是协调多个调度层，而非更换模型。

```text
末音到 Final
  = 边界确认与提交等待
  + 入队到开始执行
  + 必需模型与证据的关键路径
  + 有序发布等待
  + 序列化与传输
```

并行执行的角色与 ASR 不能直接把耗时相加，应按依赖关系计算关键路径。记录每个任务的 enqueue/start/end，并将结果绑定到 segment_id；请求总耗时只用于整体观察。

| 现象 | 先查 | 可能的处理方向 |
| --- | --- | --- |
| 单路与并发都慢 | 边界、输入长度、模型执行 | 端点分析、上下文治理 |
| 首字稳定、Final 并发长尾 | final 队列、运行时调度 | 协调容量、限制预览竞争 |
| 无队列但发布晚 | 顺序屏障、角色等待 | 截止时间、有界缓冲 |
| 重启后的首轮慢 | 实际波形路径、输入形状 | 代表性预热、冷态验收 |

## 多级并发必须按资源预算对齐

一条链路至少有入口准入、应用 worker、推理运行时序列数、角色 worker 和目标 ASR worker。任何一层限制过低都会排队；全部调大又可能引发显存不足或过载。应根据输入长度、模型缓存和同卡负载测容量，不能复制一个历史并发数字。

```yaml
# 仅为配置组织示例，字段名与数值需由实际服务定义
admission:
  max_sessions: <实测连接容量>
final:
  max_inflight: <最终识别资源预算>
  queue_deadline_ms: <业务剩余时限>
preview:
  max_inflight: <独立预览预算>
  yield_to_final: true
```

预览可以过期或被新版本替代，Final 却关联完成语义，通常应有更高优先级。队列满时按协议明确拒绝、背压或降级；不能无界堆积任务，也不能丢掉已接受的音频。目标识别和角色模式应分别压测，不从普通识别容量继承结果。

## 冷态、热态与容量边界分开

模型加载成功和健康接口通过，只证明部分初始化完成。真实波形路径、不同 batch 形状和动态长度可能在首轮触发额外初始化。预热应覆盖代表性输入，随后验证端到端输出；不能删除首轮慢请求，只保留热态数据。

容量报告至少包括总请求、成功、拒绝、超时、错误以及成功请求的平均值和 P95/P99。只统计成功时延会掩盖过载。连接数超过准入容量后明确拒绝，可以是符合设计的行为，但不能写成这些连接都已成功处理。

采用阶梯负载，在每档观察稳定状态、资源余量和排队增长，再做混合长短句及持续会话。短句测试测到的容量不自动适用于长上下文；共享设备上的其他训练或推理负载也要记录。

## 预计算与缓存：复用证据，重新作决策

在静音确认期间提前识别，可把部分计算与等待重叠。复用必须匹配精确 PCM、模型版本、配置和角色计划。输入续说、配置变化或角色计划变化时，旧结果失效；不能只按文本或相似时间范围复用。

队列接受预计算结果后，它应移交给不可变任务。会话准备器随后取消旧准备或启动新准备，不能取消已经入队的结果；队列拒绝时则由原所有者清理。这类所有权错误往往只在 EOF 和下一次准备同时发生时出现。

目标身份过滤中的缓存也应区分“声学证据”和“放行决定”。可以缓存某段精确音频的评分，但新请求仍要按当前整句长度、阈值和策略判断。缓存一个历史放行布尔值，会绕过之后改变的条件。

| 缓存性质 | 应满足的条件 |
| --- | --- |
| 键 | 输入摘要、模型/配置版本和证据范围 |
| 值 | 评分或可复核结果，不含越权的终态决定 |
| 容量 | 有界条目或字节预算 |
| 失效 | 版本、输入、角色计划或代际变化 |
| 异常 | 失败、取消、证据不足不作为成功缓存 |

## 调试与压缩不要阻塞主路径

调试包压缩曾位于全局保存锁内，使慢压缩阻塞其他会话保存。可先冻结待写数据，锁外压缩，再在锁内完成索引发布和配额更新。需要保留原子可见性：用户不能下载半成品，清理器不能删除尚在发布的文件。

降低压缩级别可以缩短诊断生成时间，但要测量体积增量、解压内容一致性和端到端收益。一个阶段快了不代表请求同幅度变快，因为它可能与其他任务并行。

## 性能优化的验收

同输入、同配置、同目标环境做前后对照，先证明文本与角色不退化，再报告冷态、热态、并发和资源变化。性能优化只关闭性能问题；身份或识别质量失败仍然保留其独立结论。
