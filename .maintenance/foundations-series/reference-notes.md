## 不直接作为结论照搬

1. API 输入/输出/命中价格是服务商、模型和日期相关的定价，不等于固定的计算成本比例。
2. Prefill/Decode 的算力或带宽瓶颈随批次、上下文、架构和硬件变化；“每步完整读一遍权重”“64 路与 1 路耗时差不多”只能帮助建立特定负载下的直觉，不能当吞吐承诺。
3. MoE 的专家放置、驻留与卸载取决于实现；不写成所有专家在所有部署条件下都必须常驻 GPU 显存。
4. TTFT 包含排队、输入处理、计算和传输；平均 TPOT 与逐 Token 的 TBT 分布也不能不加条件地等同。
5. 结构化输出约束格式，不能保证事实、参数语义或工具调用权限。角色标记转义也不代表已经解决提示词注入。
6. 推测解码的分布保持依赖正确的验证算法；速度取决于接受率与开销。框架支持列表、DeepInfer 发布信息和社区星标需另核官方记录，首批课程不引入未复核的版本事实。
