## 1. 改造目标与学习边界

将目前的“基础概念导读”扩展为“从零理解模型，到独立完成小模型训练与优化”的渐进课程。保留 `/docs/ai/foundations/` 作为正式入口，安排 24 篇主线、4 篇进阶，以及原有 4 个细节入口的兼容导读。

读者起点按没有机器学习经验、没有独立训练经验设计。Python 不作为隐含前提：前两篇提供读懂后续代码所需的变量、列表、函数、循环、数组和终端练习，复杂语法按需链接已有 Python 专题。数学从可观察的数值变化进入，先算一次预测和更新，再解释向量、导数及链式法则。

主线结业后，读者应能在普通电脑 CPU 上完成数据检查、基线、小神经网络训练、验证选型、封存方案后的测试、错误分析、优化对照、保存重载和独立推理。应能通过实验判断一次改动是否值得，定位常见输入、梯度、评估和性能问题。

进阶用于理解卷积、迁移学习、语言建模和参数高效微调。完成小模型课程不等于具备独立预训练通用大模型的资源或经验；LoRA 的低参数量也不等于任意电脑都能训练任意底座。进阶实验需另列硬件、数据、授权、下载体积和已验证范围。

## 3. 案例设计

### 3.1 连续主线：数字识别

以“把一张小尺寸数字图片识别为 0—9”为主项目。前期先展示原始图像、像素和模型预测，后期让读者独立得到模型、错误图集及推理程序。采用 scikit-learn 自带的 `load_digits` 作为 CPU 必修数据候选：官方说明为 1797 个样本，每张 8×8，像素范围 0—16，共 10 类。它不是 MNIST 的 28×28、0—255 图片，预处理和模型形状不得混用。

数据安装后可本地加载，避免主线依赖额外下载服务。正式收录前仍需核对数据来源、许可和可分发条件，固定数据内容哈希、样本 ID 与切分索引。按类分层的固定切分用于教学闭环，但不能声称证明对新书写者泛化；未确认书写者 ID 时，不编造分组切分条件。

后续加入整体变暗、平移、空白输入和不同书写风格的对照。由原图生成的所有变体继承同一分组，不能跨训练、验证与测试集合。增强只应用于训练集合；针对预定义扰动的测试与自然外部样本测试分别报告。

手绘输入是后期扩展：8×8 教学数据与用户笔迹存在分布差异。即使输入经过裁剪、居中和缩放，也不能预先承诺手绘识别良好；保留失败样例并说明预处理与数据覆盖限制。

### 3.2 数学桥梁：包裹运费估算

用一维合成数据解释 `预测运费 = w × 重量 + b`。重量、运费和残差都有明确单位，读者可以先调整两个参数，再看到预测线、残差和损失变化。学习率与损失曲面都沿用同一份数据。

合成样本由公开公式和固定随机源生成，并明确标注为教学数据。真实运费还受首重、续重、地区、体积、折扣等规则影响；已知定价规则时直接使用规则更合理。该例只解释拟合与优化，不声称发现真实物流规律，也不把相关性解释为因果。

### 3.3 按需对照案例

二维双月牙用于观察线性模型与非线性模型的表达差别，明确属于合成数据。订单复核用于二分类阈值与人工容量的教学算例，不展示为实际风控成绩。流失预测的时间窗口、迟到数据和干预反馈继续链接已有项目，避免在每篇文章切换成一套新业务。

结业分为两级：复现级在数字项目上独立完成全链路；迁移级选择一份许可清楚的新分类或回归数据，自行确定样本、输入、标签、切分、基线与指标，再复用训练和评估程序。迁移级不能只改数据文件路径，应说明新数据为何采用相应切分与模型、预处理改变在哪里，以及失败样例说明了什么。

独立 HTTP 服务、权限、容量、灰度和线上监控链接现有工程化专题；第 23 篇解释必要交付边界，不把生产平台搭建变成基础课的强制门槛。

## 5. 3D 与教学图示设计

精致感由清晰的形体、尺度、取景、标注和数值联动建立。空间维度必须有语义：高度表示损失或概率，切片表示一个真实张量轴。完整训练链路、泄漏边界、计算依赖和排错分支采用独立二维 SVG。

### 5.1 优先实现的三个 3D 场景

| 场景 | 画面与真实含义 | 可操作项与联动结果 | 必须解释的边界 |
| --- | --- | --- | --- |
| 张量切片 | 像素矩阵与批次切片；小体块的坐标对应明确的索引 | 选样本、选像素、切轴；同步原图、索引、像素值和 `[B,64]`/`[B,1,8,8]` 形状 | 3D 只帮助展示部分轴，四维张量不是物理四维实体；reshape 不任意交换轴 |
| 损失曲面与梯度 | 横轴 w、纵深 b、高度为固定训练数据计算的损失；同步二维等高线和预测线 | 拖动参数、调学习率、单步/播放/复位；显示更新前后参数、梯度和损失 | 用真实二维参数模型，不把高维神经网络假装成完整山谷；梯度下降是算法更新，不模拟有重力的小球 |
| 分类概率曲面 | 双月牙样本位于 x1/x2 平面，高度是指定类别分数，底面显示决策边界 | 切线性/MLP、选择训练步和样本；同步类别、分数、边界和验证指标 | 点的空间距离不自动等于语义距离；分数面不证明校准，不用训练集分数代替泛化 |

后续候选是卷积感受野和特征图切片，只有在能清楚展示局部覆盖与共享权重时再实现。LoRA 矩阵关系优先独立轴测 SVG，不单独引入复杂 3D 资产。Attention 主体使用二维热图和逐行计算，避免透视遮挡权重。

### 5.2 视觉与阅读规范

沿用站点系统中文字体、浅深主题及现有绿色品牌色；输入使用蓝色，预测/激活使用绿色，标签/目标使用琥珀色，梯度和错误使用克制的红色，并辅以文字或线型。颜色用于区分职责，不将整页渲染成单一绿色背景。

文章仍是阅读页。图示直接嵌入正文宽度，采用无装饰边框的场景区，控件和数值在其下方独立排布；不做课程营销首页、嵌套卡片、霓虹神经网络或自动旋转的装饰模型。桌面场景建议约 16:10，窄屏按内容改成更高的固定比例；具体高度由真实标签和首轮原型确定。

每幅图前只提出当前问题，图后解释观察与工程含义。术语先有对象再有名字，公式的符号须在附近说明。长推导放展开区；关键因果和失败边界保留在主阅读路径。

标签优先用 DOM 覆盖层保证中文清晰度，避免依赖远程字体或将密集文字烘进 3D 纹理。相机限制俯仰、距离和目标范围，初始取景完整显示轴、对象与关键标签。提供预设视角和复位，不要求读者自行寻找正确角度。

滑条配数值输入，模式用分段选择，播放/暂停、单步和复位用现有 Lucide 图标并提供可访问名称及 tooltip。支持键盘，不以拖动为唯一操作。手机单指滚动文章，显式进入交互或使用独立旋转控件后才操作场景，防止阅读时意外捕获手势。降低动态效果时保留单步，默认关闭持续播放。

### 5.3 静态兜底

所有机制图提供可引用独立 SVG，位于 `public/ai/foundations/`。3D 场景另有说明同一对象和数值的静态图、二维视图及文本数值结果，覆盖未启动 JavaScript、不支持 WebGL、上下文丢失、离线和打印。

静态图不是不完整的宣传封面；应保留理解所需的轴、图例和关键对照。修改数学模型或数据后，重新生成静态图与实验结果，防止三个版本讲述不同事实。长图按桌面和窄屏重排，保留相同关系，不以等比例缩小中文解决响应式问题。

实际浏览器推理不是首批必需项。如果后期需要手绘即时识别，再对成熟推理运行时评估新增体积、算子支持与输出一致性；不把它隐含在 Three.js 场景组件里。

## 7. 可复现实验合同

每个可下载实验必须说明执行位置、环境、输入、命令、输出文件、预期不变量、耗时测量条件和常见失败定位。脚本提供命令行入口，Notebook 不作为唯一执行方式。

拟将数字项目拆为以下可独立执行的步骤，实际文件名在实现时固定：

```text
prepare_data.py      固定样本 ID、切分与清单
train_baseline.py    多数类与简单模型基线
train_digits.py      训练候选、按验证选择检查点
evaluate.py          独立评估与错误样例导出
predict.py           新进程加载与输入合同检查
benchmark.py         固定负载下的运行成本比较
```

实验清单至少保存数据来源/许可、内容哈希、切分索引、代码与配置版本、随机种子、依赖、硬件、训练预算、预处理及类别映射。检查点保留推理所需内容；如宣称支持训练恢复，另保存优化器、调度器、当前步与必要随机状态，并实际验证中断恢复。能重载预测不等于能恢复训练。

第 14 篇只使用训练与验证结果选模型；第 15—22 篇继续在预先约定的开发协议内比较。最终测试在方案冻结后执行。课程公开一份参考测试结果可帮助复现，但已经围绕该数据做过多轮开发时，应说明估计边界；结业新增数据或另建保留集，不把公开测试反复调到最好当成独立证据。

优化报告统一比较数据/切分、训练预算、参数量、质量指标、错误类别、模型体积和实测耗时；训练时间、吞吐与推理延迟分别列出。小数据集运行波动大，报告重复测量和样本量，不提前写“提升百分之几”的占位成绩。

改变 Batch 大小时，同样 Epoch 下的更新次数本来就会改变，不能同时宣称样本暴露量、更新数和墙钟时间全部相同。先固定一种预算回答一个问题，再报告其他维度；例如等样本暴露量比较质量，等时间比较可达到的质量，分别形成结论。

主线不要求付费 API、GPU 服务器或大模型下载。首次 CPU 基线跑通后才能给出运行时间和内存建议；高级模型下载量、显存与费用另行测量并标注。未满足硬件的读者可完成概念和小规模机制实验，不能被记录为完成真实底座微调。

## 12. 配套讲解视频

2026-10-21 补充视频设计。视频、文章和实验使用同一课程目标与数据：视频解释现象与变化，文章承接推导、配置与排错，交互实验让读者修改条件验证判断。视频作为学习入口之一，正文和可下载实验仍可独立完成学习。首版采用 Python/Pillow、Matplotlib 三维曲面、macOS say 和 FFmpeg，时长 208.36 秒。同日改用“噜噜”纯音色的 25 段外部 WAV，按实际音长重排为 224.67 秒；默认渲染仅消费本地音源，不重复调用合成服务。没有新增 Manim 或 Remotion。当前制作配置、大小与摘要见 `video/manifest.json`，B 站版本见 `video/bilibili-manifest.json`。

### 12.1 视频形式与选题

先制作单个概念约 3—5 分钟的样片，验证节奏与制作成本。后续机制短片可按内容扩展，完整项目实操单独安排，避免每篇文章机械对应一条相同时长的视频。首批选择学习率、张量维度、反向传播、过拟合、错误分析五类过程，覆盖空间关系、数值更新及工程判断。

采用中文旁白、真实数据驱动动画、局部公式和操作演示。旁白每一段都有对应的观察对象，不逐字朗读文章或长代码。重点时刻暂停变化、突出当前数值，再进入下一步；相机运动用于揭示被遮挡关系，不持续绕场旋转。完整命令和代码放文章及下载文件，视频只展示理解当前机制必需的部分。

### 12.2 工具分工

| 工具 | 适合的工作 | 本项目采用方式 |
| --- | --- | --- |
| Three.js | 损失曲面、张量切片、分类概率面 | 复用课程交互场景的几何与数据，另用固定时间轴和相机渲染视频帧；按帧索引取状态，避免依赖机器运行速度 |
| Manim Community | 公式变换、向量与矩阵、计算图、逐步数值解释 | Python 编写数学动画，与训练程序读取相同数据和轨迹；中文使用本地字体，公式按需要使用 MathTex，首片先验证依赖和渲染 |
| FFmpeg | 图片序列编码、片段连接、配音混音、字幕和格式输出 | 作为首版合成工具，固定帧率、时基、分辨率及编码配置；保留音轨和字幕源文件 |
| 中文 TTS 或真人录音 | 中文讲解 | 先做短段试听，确认术语、数字、节奏和停顿，再批量制作；具体服务、费用、音色及使用条件在制作时确定 |
| Remotion | 多章节复用片头、章节标识、图文及字幕时间轴 | 批量制作阶段的候选；使用独立制作工程，不将其 React 依赖混入 VitePress 阅读页；采用前核对当时许可、环境与渲染要求 |

### 12.3 第一条样片：学习率怎样影响一次更新

建议标题为“模型怎样修改参数：梯度与学习率”，目标长度约 4 分钟，最终以讲清内容所需时长为准。

| 时间段 | 画面与讲解任务 | 读者应观察到的结果 |
| --- | --- | --- |
| 00:00—00:25 | 运费预测线与样本，展示当前预测偏差 | 参数需要改变，改变有方向和大小两个问题 |
| 00:25—01:05 | 以单样本 `x=2,y=4,w=1`、固定 `b=0`，将预测 2 转成损失 `L=0.5(wx-y)²=2` | 损失是由当前预测与目标算出的数，目标值和数据在本次更新中固定 |
| 01:05—01:50 | 单参数损失曲线、当前位置切线，逐项展示 `dL/dw=-4` | 梯度给出局部变化率，优化器沿负梯度更新参数 |
| 01:50—02:35 | 学习率 0.1 与 1 的前后对照：`w=1.4,L=0.72` 和 `w=5,L=18` | 方向相同，步长不同，损失可能下降也可能上升 |
| 02:35—03:25 | 切换到多样本两参数运费模型，显示 `w,b,L` 曲面与二维等高线，固定相机观察若干次更新 | 从一个参数扩展到两个参数，每一步仍有可检查的参数、梯度和损失 |
| 03:25—04:00 | 展示相应代码行与更新日志，给出换初始值、改学习率的练习 | 能在文章中的实验复现现象，并解释结果 |

单样本手算与多样本 3D 曲面是两个明确标识的实验。切换画面时说明数据、参数数量和损失定义变化，不能将两者数值直接拼接成一条训练轨迹。多样本曲面由真实损失计算，优化路径使用同一脚本导出，不用小球受重力滑落代替梯度更新。

### 12.4 制作与版本流程

1. 确定单一教学目标，写旁白和分镜，标明每个镜头的数据、公式、对象和变化。
2. 运行对应实验，核对公式、轨迹和失败对照，导出包含实验 ID 的数据文件。
3. 制作静态关键帧，先检查中文、坐标、标注与手机观看尺寸，再渲染短动画。
4. 录音或合成逐段中文配音，审听专有名词、字母、负数、小数和公式读法；按实际音频时长安排镜头和停顿。
5. 渲染画面并合成，导出 MP4、字幕、逐字稿、封面、章节时间点与实验版本清单。
6. 完整观看成片并在实际网页播放，复核音画同步、字幕、公式、加载和跳转后，再批量制作下一条。

旁白、分镜、渲染代码、字幕和清单放在 `.maintenance/foundations-series/video/`。原始视频、音频和帧序列的体积需实测后决定存储位置，不将大量中间文件默认加入 Git。网页引用的轻量封面与字幕可按站点约定放在 `public/ai/foundations/video/`；成片根据大小与实际带宽选择静态资源或对象存储，公开发布前核对播放链接及权限。

网页默认显示封面和原生可访问播放控件，`preload="none"`，不自动播放有声内容，不在滚动到视区时下载整条视频。逐字稿和实验链接保留在视频附近；本地字幕使用 WebVTT，跨域视频验证正确 MIME、Range 请求、CORS 和实际拖动播放。桌面与手机共用教学内容，竖版短片如需制作应重新布局，不能直接裁切公式和坐标轴。

### 12.5 视频验收与估算

- 完整观看并审听成片，关键公式、单位、参数和实验结果与文章一致；字幕及旁白版本与画面匹配。
- 以真实手机尺寸观看，检查不暂停时能否辨认关键标签；字幕避开曲线、数值、公式与播放器控件，不仅检查 1080p 原帧。
- 抽取镜头切换、数值更新及首尾关键帧做视觉检查，并播放确认动作、时序和音画同步；静态截图不能代替视频验收。
- 覆盖桌面/手机、播放/暂停、拖动、静音/音量、字幕、全屏和加载失败，报告已测浏览器与设备范围。
- 确认配音音色、语料、字体和素材使用条件；不自动克隆真人声音。未选择配音服务时不调用付费接口。
- 第一条样片测量分镜、动画、配音、每帧渲染、编码、文件体积和检查耗时，再给系列工期与带宽估算。视频长度不能直接换算制作时间；改旁白可能需要重新调整整个时间轴。
