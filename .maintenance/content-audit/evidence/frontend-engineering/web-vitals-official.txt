    - paragraph:
      - text: 当指标最初开发并进入生态系统时，会被视为实验性指标
      - emphasis
      - text: 。
    - paragraph:
      - text: 实验阶段的目的是评估指标的适用性，首先是探索要解决的问题，并可能迭代之前的指标可能未能解决的问题。例如，
      - link "Interaction to Next Paint (INP)":

    - heading "待处理" [level=4]
    - paragraph:
      - text: 当 Chrome 团队确定实验性指标已收到足够的反馈并证明其有效性时，该指标将成为待处理指标
      - emphasis
      - text: 。例如，INP 在 2023 年从实验性指标升级为待处理指标，目的是最终停用 FID。
    - paragraph: 待处理指标在此阶段至少保留六个月，以便生态系统有时间适应。随着越来越多的开发者开始使用该指标，社区反馈仍然是此阶段的一个重要方面。
    - heading "稳定" [level=4]
    - paragraph:
      - text: 当核心网页指标候选指标最终确定后，它将成为稳定指标
      - emphasis
      - text: 。此时，该指标可以成为核心网页指标。

    - paragraph: Web Vitals 和 Core Web Vitals 代表了开发者目前可用于衡量网络体验质量的最佳信号，但这些信号并不完美，未来可能会进行改进或添加。
