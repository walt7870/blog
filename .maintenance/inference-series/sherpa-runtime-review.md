# 2026-10-23 语音推理框架补充

## 范围与叙述

沿虚构资料助手“年假怎么申请？”继续解释语音推理。第一篇只补声音也属于推理的定位，完整机制落在第 11 篇；第 12 篇增加语音选型和独立日期的版本快照。总览仅增加语音阅读入口，保留进入任务前已存在的数值精度专题调整。

第 11 篇以声音采样、特征、模型输出、文字、回答、音频和播放的变化组织教学。独立 SVG 展示 sherpa-onnx 对语音任务的组织及 ONNX Runtime 的执行职责，沿用系列字体与蓝绿配色；桌面横排、手机纵排。图中仅表达常见识别路线，不把循环解码、端点与打断的完整时序压成串行性能模型；原有语音时延与打断图继续承担这些解释。

两种交互分别展示数据与责任交接、热词配置条件的因果。固定教学样例不录音、不请求真实模型；热词实验不伪造声学分数、识别成功率或错误配置的具体 SDK 行为。
