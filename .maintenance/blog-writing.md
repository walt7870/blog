# 博客写作与验收原则

适用于新增文章、专题扩展和已有页面的大幅改造。项目级约束以 `AGENTS.md` 为准；本文件供写作和审查使用，不作为对外知识正文。质量以读者能否理解、判断和复现为准，不设置统一字数、标题数或图片数量指标。

下面的案例、图文与阅读体验要求针对对外文章。仓库协作规则和维护台账核对准确性、可执行性及引用即可，不为它们新增读者入口或知识图示；若修改了主题组件或公开页面，仍须验收相应页面。

## 先确定页面职责

写作前阅读专题总览、相邻文章和导航，明确读者带着什么问题进入、已经需要知道什么、读完能够完成什么。一次只解决一个主问题，次要问题链接到详细页，避免每篇重复从基础讲起。

| 页面类型 | 应交付的内容 | 应控制的内容 |
| --- | --- | --- |
| 总览 | 问题背景、概念关系图、通俗案例、选读路径和完整子模块入口 | 完整代码、参数清单、重复定义 |
| 机制 | 对象关系、生命周期或数据流、贯穿案例、边界与取舍 | 脱离运行过程的术语堆积 |
| 实操 | 环境与前提、执行入口、最小步骤、预期结果、失败排查与恢复 | 没有解释的长命令和配置 |
| 经验 | 触发场景、根因证据、方案比较、失败反例、验收结果和适用范围 | 工作流水、没有证据的收益 |
| 速查或迁移 | 可定位的用法、限制、替代入口 | 为凑篇幅添加概念和装饰图 |

这些是内容职责，不要求逐字套用为章节标题。用连续段落讲清因果；列表用于步骤和检查，表格用于相同维度的比较。

## 用案例解释机制

机制、教程和经验页至少让一个案例走完“触发条件 → 处理过程 → 可观察结果”。涉及容易误用的结论，还要给出失败条件或不适用情况，以及读者如何判断。

例如，“异步导出能提升用户体验”只有结论。可改为：用户请求导出一整年的账单，同步接口可能在文件生成前超时。接口先检查账户权限并返回任务编号，后台读取限定字段生成文件，用户通过任务状态获取下载入口。重复提交时按幂等键复用任务；生成失败则记录错误并限制重试。验收既检查任务状态和文件字段，也用另一账户尝试下载，确认权限校验发生在下载请求上。数据很少、生成时间稳定时，同步下载可能更简单。

这个案例应与正文中的状态图、接口和排错说明使用同一组名称。教学案例不伪装成线上事故；实测效果说明环境、样本、指标和限制，不能从单次示例外推出性能或生产可靠性。

## 图示承担解释任务

流程、架构、状态、生命周期、数据流等正文应配独立SVG，表达真实的参与者、方向、分支和异常恢复。数量变化可用比例图或曲线，真实产品可用原始截图，选择比较可用表格；不要用不相关图片填充页面。

图前说明正在回答的问题；图后解释关键箭头、分支或数量变化，以及它如何影响实际判断。总览优先展示整体关系，复杂细节拆图并链接。图示正文中文，技术标识保留原文，沿用项目字体和配色。制作前读取 diagram-design 技能，源稿留在 `.maintenance/`，成品放 `public/<主题>/`。

浏览器中检查实际中文字体、文字边界、连线标签避让和画布裁切；在桌面、390像素窄屏、浅深色及放大视图复核。窄屏需要能看全整体或能明确放大查看，不能只留下被裁切的局部。SVG里的正确性与正文同样需要核对，不能只检查文件存在。

## 让操作可以复现

代码和命令只保留完成理解与验证所需的部分。说明版本和操作系统边界、工作目录、输入数据、环境变量、执行命令、预期输出和失败定位；密钥使用占位符，不写真实凭据。耗时或有副作用的步骤交代影响及恢复方法。

能实际运行的示例应运行，并记录结果；依赖外部硬件、GPU、付费接口或业务环境而没有运行的部分，明确验证限制。区分语法检查、单元测试、模拟集成、真实调用和生产验证，不以其中一项替代其他项。

AI相关示例要区分模型推断、检索证据、工具执行和程序约束。写清上下文或模型输入、输出校验、权限、失败停止与必要的人工确认；模型自评或一次成功回答不能证明正确。锁定依赖前检查已知漏洞和维护状态，已有漏洞且无法修复时说明影响和隔离边界，不把复现锁文件描述成生产部署方案。

## 发布前检查

- [ ] 页面有明确职责，与总览、相邻页和侧边栏对应，没有重复扩写已有详细页。
- [ ] 全文已读；没有空标题、占位段落、只有定义的章节、无解释的长代码或对话痕迹。
- [ ] 案例具有触发、过程、结果与适用边界，重要结论有机制、验证或事实支持。
- [ ] 版本和日期已核对，示例与实测结果区分清楚；推荐依赖的风险已处理或明确说明。
- [ ] 图示和正文术语一致，方向、分支、异常恢复正确，图后有解释；不配图的速查或迁移页已记录理由。
- [ ] 新页面及必要资源、专题入口和侧边栏齐全，旧路径的迁移和引用保持可达。
- [ ] 实际桌面及窄屏、浅深色全文检查完成；图示放大可用，表格与代码局部滚动，整页无横向溢出。
- [ ] 中文搜索能找到页面并实际跳转，站内导航和图片路径包含正确的 `/blog/` 前缀。
- [ ] `npm run docs:build` 通过；逐页审查台账已记录本次事实核对、保留或改造理由与实际验证结果，`node script/audit-site.mjs --gate` 通过。

自动扫描只检查可自动确认的结构、引用和审查摘要，不代替阅读全文、事实判断与视觉检查。新增页和修改页逐个验收；共享组件变化后扩大到所有受影响页面，不能用抽查代表全部。

事实错误、失效操作、图文矛盾、无法访问的资源、未说明的安全风险或未完成的必要验收，任一存在都不能标记完成。资料核对和验证证据留在 `.maintenance/`，对外正文只保留有助于读者判断和实践的内容。提交使用中文说明；实际部署按 `AGENTS.md` 的备份、文件集对比和线上客户端验收流程执行，不能以提交或HTTP 200代替发布成功。
